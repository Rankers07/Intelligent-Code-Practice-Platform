
🚀 Intelligent Code Practice Platform -:

A full-stack coding practice platform built using the MERN Stack, integrated with Judge0 API for real-time code execution, along with AI-powered assistance and video explanations to enhance the learning experience.

📌 Overview

This project is a LeetCode-style platform where users can:

Practice coding problems
Execute code in multiple languages
Get AI-based hints & explanations
Watch video solutions
Track progress

It is designed to simulate a real interview preparation environment.

🛠️ Tech Stack
Frontend:
React.js
Redux Toolkit
Tailwind CSS / CSS
Axios

Backend:
Node.js
Express.js

Database:
MongoDB

Integrations:
Judge0 API (Code Execution)
AI Integration (Hints / Explanation)
Video Embedding (Solution walkthrough)

✨ Features
👨‍💻 Coding Platform
Solve DSA problems (easy → hard)
Real-time code execution using Judge0
Multiple programming languages support

⚡ AI Assistance
Get hints when stuck
AI-based code explanation
Helps beginners understand logic faster

🎥 Video Solutions
Each problem includes video explanation
Improves conceptual clarity

🔐 Authentication System

📊 Progress Tracking
Track solved problems

🧠 Clean UI/UX
LeetCode-like interface
Responsive design

2️⃣ Install dependencies :-

Frontend:
cd client
npm install
Backend:
cd server
npm install

3️⃣ Environment Variables

Create a .env file in the server folder:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
JUDGE0_API_KEY=your_api_key
AI_API_KEY=your_ai_key

4️⃣ Run the project

Start backend:
cd server
npm run dev

Start frontend:
cd client
npm start
